## 上次踩过的坑
- modernc SQLite 中，带参数的多语句 Exec 参数绑定不可靠，要拆成单条语句执行。
- `pkill -f 'release/sonora'` 会匹配到发起命令的 shell 自身。停止服务时单独执行 pkill，或者记录 PID 后按 PID 结束。
- 删除带变量的路径时写成 `"${D:?}"/x`，否则会被安全检查拦下。
- Playwright 使用 ../palace 中已安装的版本：把脚本临时复制到 ../palace 目录下运行，用完删除。截图放在 Git 忽略的 .local/ 下。

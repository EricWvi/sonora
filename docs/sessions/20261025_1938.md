播放端的架构要点：
- frontend/src/core/player/PlayerController.ts 就是 Playback，是播放状态、队列与播放模式的唯一所有者。
  - 方法名沿用 SPlayer；store 的 playStatus、playLoading 只由它的 setState/sync 写入。
  - 依赖从构造函数注入（PlaybackDeps）。浏览器里的默认依赖在 core/player/browserDeps.ts；fixture 模式用不出声的 SilentAudioPlayer 和内存存储。
- 队列条目是 Track 加 entryId，允许重复入队，比较一律用 entryId。
- 队列与位置存在 IndexedDB 的 sonora/player。
- 均衡器按 status store 的 eqEnabled、eqBands 应用，输出设备按设置 playDevice 应用。两者的设置界面属于阶段 5。

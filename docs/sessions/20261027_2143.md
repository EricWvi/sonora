经验：
- 截图对照：
  - task test:visual 中 AMLL 的 set-yrc-amll、full-yrc-amll 偶发不符，在 HEAD 上也频繁出现，差异像素数固定（如 17946、20727、21733、18541）。原因未查明，Eric 同意的话可以专门查一次。
  - 判断是否回归：用 git stash -u，在 HEAD 上用同样的 --only 跑多次，比较不符的次数和像素数。
  - 只跑一个状态：task test:visual -- --viewport 1440x1000 --only '^状态$'。
  - 当前基线结果：54 个状态，12 一致、41 例外、1 不符（AMLL 偶发）。
  - 加载 fixture 状态的路径（initPlayer → loadState）上不要多加 await。
- 设置相关：
  - setting store 与 shortcut store 导出 defaultSettingState / defaultShortcutState。
  - fixture 的设置只存在内存中，GET 返回 {}。
  - 设置弹窗是 .main-setting，菜单项用 ".main-setting .n-menu-item" 加 hasText；设置项元素是 #setting-<key>。
  - 顶栏设置按钮是 button[aria-label='设置']，再点“全局设置”。
- 无头真实播放：
  - 开发服务器上可以在页面里 await import("/src/core/player/PlayerController.ts")，再 usePlayerController()。引擎是 .deps.engine，预加载地址是 engine.preloadUrl。
  - pinia 从 document.querySelector("#app").__vue_app__.config.globalProperties.$pinia 取，store 名称为 data、music、status、setting、shortcut。
  - 用真实点击触发播放。注意播放超过 30 秒会写入最近播放；对 Eric 的开发实例做测试时要在 30 秒内暂停，或者改用 fixture（?fixture=library&player=paused）。
  - 输出设备：启动参数加 --use-fake-device-for-media-stream --use-fake-ui-for-media-stream，BrowserContext 的 permissions 加 microphone。字体列表要在 permissions 加 local-fonts。
  - 用本机 Google Chrome：chromium.launch({ channel: "chrome" })（156）。
  - 底部栏按钮：.main-player .play-pause；右侧均衡器按钮 .right-menu .menu-icon[title='均衡器']。
  - SongList 的表头也带 .song-card 类，选歌曲行用 ".virtual-item .song-card"。
  - 下拉菜单里父项也包含子项文字，用 hasText 选择时可能匹配多个，要加 .last()。
  - 真实曲库副本：337 首歌、310 张专辑、194 位艺术家。专辑 31《邓丽君精选1》有 5 首歌，专辑 310 只有 1 首。

经验：
- 截图对照（首版不再强制，但播放器相关改动后仍要跑 task test:visual）：
  - 当前基线结果（2026-10-28）：54 个状态中 12 一致、42 例外、0 不符。一次全量约 4 分钟。
  - 若出现不符：git stash -u，在 HEAD 上用同样的 --only 跑多次，比较不符次数与像素数。只跑一个状态：task test:visual -- --viewport 1440x1000 --only '^状态$'。--base 可连已有的 Vite。
- 无头浏览器与 store：
  - pinia 从 document.querySelector("#app").__vue_app__.config.globalProperties.$pinia 取，store 名称为 data、music、status、setting、shortcut、sonora-user。
  - 可以在页面里 await import("/src/api/source.ts") 直接调用 source（tracks、createPlaylist、addToPlaylist(id, trackIds) 等）。
  - 用真实点击触发播放；播放超过 30 秒会写入最近播放。对 Eric 的开发实例做测试时要在 30 秒内暂停，或者改用 fixture（?fixture=library&player=paused）。
  - Media Session：用 context.addInitScript 包装 navigator.mediaSession.setActionHandler 与 setPositionState 记录调用，再直接调用记录下的操作模拟系统控件。
  - 巡检可点击元素：找最外层 cursor: pointer 的可见元素，在重新载入的页面上真实点击，记录 MutationObserver、请求、URL 与剪贴板变化；剪贴板读取要写成 navigator.clipboard?.readText()。
- 页面选择器：
  - 搜索框 input[aria-label='搜索音乐']；建议面板 .search-suggest；结果页 .search .n-tabs .n-tabs-tab。
  - 歌曲行 ".virtual-item .song-card"（双击播放）；底部栏 .main-player .play-pause，封面 .main-player .cover（点击打开全屏播放器）；侧栏 #main-sider，顶栏 #main-header，内容 #main-content；全屏播放器 .full-player。
  - 下拉菜单选项用 ".n-dropdown-option:visible" 加 hasText 与 .last()。菜单打开时 Escape 关不掉，再开菜单前先点空白处。
  - 播放端路由是 hash 模式（#/songs、#/album?id=、#/artist/songs?id=、#/playlist?id=、#/search/songs?keyword=）；管理后台是 history 模式，base /admin/（login、upload、tracks、albums、artists）。
- 模拟异常：
  - 会话失效：用 page.route 让 /api/v1/** 返回 401，同时拦截 /auth/login。
  - 不可达：用 ss -ltnp 找到后端 PID 后 kill，再重新启动。
- 临时实例：
  - 后端：cd backend && go build -tags dev -o /tmp/<目录>/sonora ./cmd/sonora。数据库用 sqlite3 .backup 复制，covers 直接复制。配置写 listen 127.0.0.1:14570、data_dir、media_dir、dev: true。
  - 媒体目录：只读场景可以软链接整个 backend/.data/media；要用管理 API 删歌时，必须用 cp -rs 逐个文件建软链接。
  - 管理 API：dev 下 POST /admin/api/v1/login {"username":"admin","password":"admin"}，删除用 DELETE /admin/api/v1/tracks/{id}。播放端 cookie 用 curl -c 访问 /auth/login 获得。
  - 播放端 Vite：配置写在 /tmp，从 frontend/node_modules/vite/dist/node/index.js 绝对路径导入 mergeConfig，再导入 frontend/vite.config.ts，root 设为 frontend，proxy 的 /api、/auth 指向临时后端，端口 14572；在 frontend 下用 node node_modules/vite/bin/vite.js --config <配置> 启动。
  - 管理后台 Vite：同样做法，从 admin/node_modules 导入 mergeConfig 与 admin/vite.config.ts，root 设为 admin，port 14573，proxy 的 /admin/api 指向临时后端；访问 http://127.0.0.1:14573/admin/。
  - 停止前用 ss -ltnp 核对实际 PID，再按 PID 结束。
  - 真实曲库副本：337 首歌、310 张专辑、194 位艺术家；曲库里没有歌单。
- /tmp 下的 Playwright 脚本：import pw from "/home/eric/projects/palace/node_modules/@playwright/test/index.js"，再 const { chromium } = pw；在 ../palace 目录下运行。

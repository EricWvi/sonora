- 全屏播放器按 Escape 关不掉。脚本里通过 pinia 设置 status.showFullPlayer = false。
- 无头真实播放：
  - 开发服务器上可以在页面里 await import("/src/core/player/PlayerController.ts")，再 usePlayerController()。
  - 均衡器的实际增益：usePlayerController().deps.engine.effectManager.filters[i].gain.value。
  - pinia 从 document.querySelector("#app").__vue_app__.config.globalProperties.$pinia 取，store 名称为 data、music、status、setting。
  - 用真实点击触发播放，否则会受自动播放限制。
  - 剪贴板：BrowserContext 加 permissions: ["clipboard-read", "clipboard-write"]。
  - 底部栏按钮：.main-player .play-pause、.main-player .like；上一首、下一首是 .play-control .play-icon 的第 2、3 个。
  - 全屏播放器的歌词菜单是 .lyric-menu .menu-icon；底部栏右侧菜单是 .right-menu。
  - 歌词行是 #lrc-<序号>。
  - 制造播放失败：page.route 拦截 resourceType 为 media 的请求并 abort。
  - 播放端路由是 hash 模式（/#/album?id=31）。
  - 真实曲库副本：337 首歌、310 张专辑、194 位艺术家，没有艺术家图片。专辑 310《你的答案》有歌词；歌曲 248 有 3 位歌手。

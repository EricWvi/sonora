经验：
- 临时实例：
  - 后端：go build -tags dev 输出到 /tmp，配置写 listen 127.0.0.1:14570、data_dir、media_dir、dev: true。要用真实数据时，复制 backend/.data/data（本机 337 首的曲库副本，数据库版本 6；新程序启动时会自动迁移到 7）；媒体用 cp -as 建软链接。
  - 播放端 Vite：配置写在 /tmp，从 frontend/node_modules/vite/dist/node/index.js 绝对路径导入 mergeConfig，再导入 frontend/vite.config.ts；root 设为 frontend，proxy 的 /api、/auth 指向 14570，端口 14572。
  - 管理后台 Vite：做法相同，导入 admin/vite.config.ts，proxy 的 /admin/api 指向 14570，端口 14573。开发管理员是 admin/admin，可以直接 POST 14570 的 /admin/api/v1/login。
  - 停止前用 ss -ltnp 核对 PID，再按 PID 结束。
- 无头浏览器：
  - Playwright 是 CommonJS：import pw from "/home/eric/projects/palace/node_modules/@playwright/test/index.js"，然后用 pw.chromium；在 ../palace 目录下运行。
  - 输出直接写文件，不要接 tail。

参照项目的事实（只从 GitHub 核对过，没有构建）：
- 技术栈是 Kotlin、Jetpack Compose、Material 3、Media3（FFmpeg、无缝播放、交叉淡化），要求 Android 11+（API 30）、编译与目标 SDK 37、JDK 21。包名 com.lostf1sh.pixelplayeross，要换成 Sonora 自己的。
- 最接近 Sonora 的代码是 Navidrome/Subsonic 与 Jellyfin 的接入：data/navidrome、data/jellyfin、data/network/*、data/worker/*SyncWorker.kt。
- 离线下载的代码：data/offline/CloudOfflineRepository.kt、data/worker/CloudTrackDownloadWorker.kt、OfflineTrackDao、CloudDownloadsScreen。

Sonora 服务端的关键事实（客户端对接时用）：
- 播放端 API 前缀是 /api/v1/，见 docs/api.md。网易云功能全部由 Go 转发，客户端不直接访问网易云，Cookie 只保存在服务端。
- 播放地址带时效，不能存入队列。本地与网易云的歌曲 ID 可能相同，比较要带来源（Web 端是 frontend/src/utils/track.ts 的 sameTrack、trackKey）。
- 音频响应现在是 private, no-cache（阶段 9 有“音频 immutable 缓存”候选，和客户端缓存相关）。
- 只有配置了 import_group 才请求 groups scope，否则 Authelia invalid_scope 会让所有人登录不了。

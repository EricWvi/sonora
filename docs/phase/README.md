# 阶段计划

更新日期：2026-11-07。本目录把[重写路线图](../roadmap.md#7-分阶段路线)的阶段 1–9 拆成可执行的工作包。原则、数据契约与样式验收标准仍以路线图为准；本目录记录每个阶段的当前状态、具体任务、交付物和退出证据。

**样式硬性约束对播放端的每个阶段都有效**（2026-10-24 明确范围）：播放器（全屏播放器、底部播放栏、播放队列抽屉）严格复刻，交付前与 SPlayer 同条件截图对照；SPlayer 所有视觉相关代码（主题、取色、样式、歌词与外观设置项）都复刻；其他页面视觉语言一致、结构自行设计。验收方法见[样式还原与验收方法](../roadmap.md#6-样式还原与验收方法)。功能完成不能代替视觉验收。管理后台不受此约束。

## 已确定的产品形态（2026-10-23）

Sonora 是自托管的音乐流媒体服务，由三部分组成：

| 部分     | 职责                                                                                                                                                                                            |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 播放端   | Web 前端 `frontend/`，播放器严格复刻 SPlayer，其他页面沿用其视觉语言。用户体验是流媒体服务：浏览歌曲、专辑、艺术家、歌单，搜索与播放；不接触文件和目录，没有文件夹浏览。通过 OIDC 登录 Authelia |
| 管理后台 | 独立 Web 工程 `admin/`，Naive UI 默认风格。首次使用时凭容器日志中的初始化 token 在页面上创建管理员；上传音乐与维护元数据、封面、歌词                                                            |
| Go 服务  | 运行在容器中，音乐文件存放在服务独占的挂载卷；为播放端和管理后台提供 API 与音频流，并托管两份前端产物                                                                                           |

其他已确定事项：

- 只支持桌面版 Chrome，不考虑移动端。2026-11-07 调整：Web 播放端仍是如此；手机上使用[阶段 8](phase-8-android-client.md) 的安卓客户端。
- 音乐只能通过管理后台上传入库。
- 播放端认证完全照搬 `../homepage` 的 OIDC 实现；喜爱、歌单与历史按用户隔离。
- 开发环境写死一个管理员和一个普通用户，跳过初始化页面、初始化 token 与 OIDC。
- 先做管理后台。播放端页面清单与设计取舍已于 2026-10-24 确定，见[阶段 2](phase-2-player-baseline.md#已确定2026-10-24)。
- 与网易云接口相关的页面和入口全部不做。2026-11-04 调整：只接入[阶段 7](phase-7-netease-and-menus.md) 列出的部分。
- 标志图形暂时复用；界面中所有 SPlayer 名称与文字换成 Sonora。
- 播放器的视觉基线直接截取本机 SPlayer 参考实例，歌曲数据来自网易云；其他页面不设逐页基线。
- 2026-11-02 Eric 确认：对标 SPlayer 的开发已基本完善，此后可以进行不照搬 SPlayer 的改动，改动处写明与 SPlayer 的差异；改动视觉方案仍须 Eric 同意（见[阶段 6](phase-6-first-release.md#已确定2026-11-02)）。

## 使用约定

- 状态只写有证据支持的结论。每条任务完成时，在对应文件勾选并附上证据位置（提交、截图对照目录、测试命令或实验记录）。
- 证据分三级：**源码确认**、**运行确认**、**待验证**。不把源码存在写成运行正常。
- 需要 Eric 决定的事项在各阶段的“待决事项”中列出；未确认前不擅自取舍，也不阻塞可并行的工作。
- 访问 SPlayer 参考实例按[浏览器会话说明](../splayer-session.md)执行。凭据不进入本目录、截图元数据、日志或测试产物；含账号个人信息的截图与数据快照只存放在 Git 已忽略的 `.local/` 下。

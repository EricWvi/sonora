# 阶段 6：首版

状态：未开始。前置：阶段 5 退出。

## 工作包

- [ ] 关闭剩余视觉欠账，每页附对照证据。
- [ ] 接入 Media Session 与页面内快捷键；不实现托盘、全局快捷键或桌面窗口行为。
- [ ] 稳定性：大曲库（固定规模）列表滚动、长时间连续播放、睡眠唤醒、服务重启、资源释放、数据库升级。
- [ ] 性能：实测冷启动、入库耗时、搜索响应、首音延迟、持续播放内存与 CPU，基于实测设预算。
- [ ] 部署：容器镜像由 CI 构建，包含 Go 服务、播放端与管理后台的生产产物；提供存储卷与数据卷的挂载说明、管理员初始化说明（从容器日志获取初始化 token），以及在 Authelia 中注册 OIDC 客户端的说明；只在桌面版 Chrome 上验证。首次部署时在真实 Authelia 下用浏览器走一遍播放端登录与退出（由阶段 4 转入）。
- [ ] 处理所有占位入口，不保留看似可用却无行为的界面。

## 退出条件

- 首发页面清单全部有功能证据和视觉证据。
- 数据升级有恢复办法，已知缺陷与支持限制有记录。

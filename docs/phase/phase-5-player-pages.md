# 阶段 5：播放端功能页面

状态：未开始。前置：阶段 4 的认证、API 与播放闭环。

## 工作包

- [ ] 全部歌曲、全部专辑、全部艺术家，以及专辑、艺术家详情接入真实曲库数据。
- 首页保持纯静态，不在本阶段接数据。
- [ ] 歌单：新建、重命名、删除、添加/移除歌曲、排序；由 Go 服务持久化，写入后重新读取验证。
- [ ] 我喜欢与最近播放：按用户隔离，由 Go 服务持久化，写入未确认时不显示为已保存。
- [ ] 搜索：歌曲、专辑、艺术家、歌单，以及建议与无结果状态。
- [ ] 歌曲右键菜单与歌曲信息弹窗，仅保留 Sonora 可用的操作。
- [ ] 设置：外观与播放相关设置。
- [ ] 异常状态：空曲库、服务不可达与恢复、歌曲已被管理后台删除、登录会话失效。
- [ ] 每个页面按阶段 2 基线完成视觉对照，关闭对应视觉欠账。

## 退出条件

- 首发页面清单中的每个页面都接入真实数据，功能与视觉证据齐全。
- 管理后台修改曲库后，歌单、喜爱和历史仍保持正确。

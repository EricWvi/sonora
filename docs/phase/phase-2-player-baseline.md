## 已确定（2026-10-24）

### 复刻范围

- **播放器严格复刻**，以截图对照验收：全屏播放器（封面、歌词、背景、控制栏及其各种模式与背景样式）、底部播放栏、播放队列抽屉。
- **SPlayer 所有视觉相关代码都复刻**：全局主题（明暗、主题色、封面动态取色）、Naive UI 主题覆盖、全局样式、组件样式、动效、歌词样式设置项、播放器外观设置项。
- **其他页面只要求视觉语言一致**：沿用同一套颜色、字体、圆角、阴影和组件（歌曲行、封面卡片、列表头、按钮、菜单、弹窗），页面结构与信息组织按 Sonora 自行设计，不与某个 SPlayer 页面逐像素对照。

### 播放器里与 Sonora 不对应的元素

| 元素 | 处理 |
| --- | --- |
| 评论按钮、`Official` 标签 | 去掉，其余按钮位置不变 |
| 音质标签（`HQ`、`SQ` 等）、音质切换按钮与菜单 | 都不显示。Eric 不打算保留占空间的无损文件 |
| `YRC` 等逐字歌词标记 | 有逐字歌词时显示 |
| 均衡器、添加到歌单、喜欢 | 保留 |

### 歌词

- 支持逐字歌词，歌词全部由 Eric 经管理后台上传，不接外部歌词源，不支持 YRC、QRC。
- 服务端保存歌词原文与格式标记 `lrc` / `ttml`；播放端复用 SPlayer 的解析代码（[parseLrc.ts](../../reference/SPlayer/src/utils/lyric/parseLrc.ts)、[lyricParser.ts](../../reference/SPlayer/src/utils/lyric/lyricParser.ts)）与 AMLL 的 `parseTTML` 解析，用 AMLL 渲染。
- LRC 的普通、逐字、增强型（ESLyric）由播放端按 SPlayer 的规则识别；相同时间戳的第二、三行为翻译与音译。TTML 内嵌翻译、音译与背景人声。每首歌一份歌词。
- 管理后台接受 `.lrc` 与 `.ttml`，文件夹上传时匹配同名外置文件；音频内嵌歌词按 LRC 处理。

### 信息架构

```text
侧栏                          顶栏：后退/前进 · 搜索框 · 用户（名称、退出）· 设置
├ 首页
├ 歌曲        全部歌曲，可排序
├ 专辑        封面网格 → 专辑详情
├ 艺术家      网格 → 艺术家详情（歌曲 / 专辑标签页）
├ ──────
├ 我喜欢的音乐
├ 最近播放
├ ──────
└ 创建的歌单  [+]
   └ 各歌单   → 歌单详情（可拖动排序）
```

- 歌曲、专辑、艺术家分成三个入口，不合并成带标签页的“音乐库”。
- 首页：问候语、快捷入口、“最近添加的专辑”、“最近播放”。
- 搜索结果：歌曲、专辑、艺术家、歌单（只含自己的歌单）。
- 状态页：404、500。
- 不做：文件夹浏览、为我推荐的推荐内容、发现音乐、排行榜、歌手发现、新歌、播客电台、视频/MV、评论、歌曲百科、每日推荐、私人漫游、心动模式、云盘、下载、网易收藏、收藏的歌单、网易登录、流媒体服务器接入、本地歌曲、桌面/任务栏/状态栏歌词，以及移动端布局。

### 歌曲列表

- 列：序号、标题（封面与艺术家）、专辑、操作（喜欢）、时长。不显示大小。
- 排序：默认、标题、歌手、专辑、时长、添加时间，升序或降序；列表分页，排序由服务端完成。专辑详情默认按碟号与曲目序号。
- 右键菜单：立即播放、下一首播放、添加到歌单、从歌单中删除（在歌单中时）、查看专辑、查看艺术家、同名搜索（在曲库中搜索）；更多操作 → 复制歌曲名称、复制更多信息。

### 详情页头部（沿用 [ListDetail.vue](../../reference/SPlayer/src/components/List/ListDetail.vue) 的样式）

| 页面 | 封面 | 信息 | 操作 |
| --- | --- | --- | --- |
| 专辑 | 专辑封面 | 标题、艺术家（可点击）、年份、歌曲数、总时长 | 播放全部、更多（添加到歌单）、列表内搜索 |
| 歌单 | 歌单中第一首有封面的歌的封面，都没有时用 SPlayer 默认封面 | 名称、简介、歌曲数、创建与更新时间 | 播放全部、编辑、删除、列表内搜索 |
| 艺术家 | 管理后台上传的艺术家图片 | 名称、歌曲数与专辑数 | 播放全部，“歌曲 / 专辑”标签页 |
| 我喜欢的音乐 | SPlayer 默认封面 | 歌曲数 | 播放全部、列表内搜索 |

专辑详情按碟号分组，多碟专辑才显示分组标题；分组标题是 SPlayer 没有的元素，按其视觉语言设计。

### 设置

保存位置采用折中方案：外观与歌词设置按用户保存在服务端，换电脑后保持一致；输出设备、音量等与设备相关的设置保存在浏览器中。

| 分类 | 保留 |
| --- | --- |
| 外观 | 主题模式、主题配置（主题色、封面取色）、全局字体、播放器外观全部项（样式、封面/歌词占比、背景样式及动画参数、展开动画、主色跟随封面、动态封面、音乐频谱）、界面元素显示、歌曲列表显示、页面切换动画、侧边栏管理、首页栏目 |
| 歌词 | “歌词设置”全部项、Apple Music-like Lyrics 全部项、替换歌词括号内容 |
| 播放 | 自动播放、下一首预载、记忆上次播放位置、阻止系统息屏、进度条悬浮信息、进度调节吸附歌词、渐入渐出、均衡器、音频输出设备、音频与歌词同步补偿、音量平衡 |
| 常规 | 搜索历史、搜索建议（来自曲库搜索）、备份与恢复、重置 |
| 快捷键 | 页面内快捷键 |

字体在 Chrome 中通过 Local Font Access 列出，未授权时手动输入字体名。

不做：在线服务、音质、音乐解锁、Fuck AI/DJ 模式、评论、特权/脏标/原唱翻唱标签、播放引擎切换（只用 Web Audio）、自动混音、歌词源优先级、QM 歌词、在线 TTML、繁体中文、桌面/任务栏/状态栏歌词、全局快捷键、无边框窗口、关闭行为、协议唤起、自动更新、本地歌曲、缓存、下载、代理、真实 IP、流媒体服务器、WebSocket、Discord RPC、Last.fm、热搜榜、分享链接、自定义代码注入。

### 播放行为

- 最近播放：播放超过 min(30 秒, 歌曲时长的一半) 才记录。
- 播放队列与播放位置保存在浏览器中；跨设备接续以后再考虑。
- 播放模式：顺序、列表循环、单曲循环、随机。
- 点击列表的“播放”：专辑、歌单、我喜欢、最近播放把整个列表放入队列；全部歌曲与搜索结果只放入已经加载的部分。
- 播放失败自动跳过，最多连续 3 首，之后停止并提示错误。

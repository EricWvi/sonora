## 工作包

### 0.1 同数据对照方案

- [ ] 采集参考图时，同时记录页面显示的数据（标题、艺术家、专辑、时长、封面、计数）。Sonora 的 fixture 复现同一组数据，保证对照时数据一致。
- [ ] 网易推荐内容会变化：同一组参考图与数据快照一起采集，需要重采时整组更新。
- [ ] 截图和数据快照含账号个人信息（昵称、头像、个人歌单），只存放在 Git 已忽略的 `.local/` 下，不入库。

### 0.2 基线环境与噪声校准

- [ ] 固定环境：系统、Chrome 版本、字体、视口（`1440×1000`、`1280×800`、`1024px` 两侧）、DPR、主题、侧栏状态。
- [ ] 处理动态因素：首启协议弹窗、问候语时间、动画、封面取色。
- [ ] 重复采集同一页面测量噪声，作为阈值依据。

- [ ] 首页：问候区。

状态：暂缓，排在管理后台之后。参照路线图：[样式还原与验收方法](../roadmap.md#6-样式还原与验收方法)。

## 当前事实

`frontend/` 已有主框架（[AppLayout.vue](../../frontend/src/layout/AppLayout.vue)）、侧栏菜单、顶部导航、明暗主题和窄屏抽屉；界面名称已改为 Sonora，标志图形沿用 SPlayer。菜单和路由（[router/index.ts](../../frontend/src/router/index.ts)）仍按 SPlayer 在线模式建立，包含为我推荐、发现音乐、播客电台、我的收藏和在线歌单分组，不符合首发范围。没有播放器、卡片、歌曲列表、弹窗或视觉比较工具，也尚未与基线对照。

## 工作包

### 1.1 菜单与路由按首发页面重建

- [ ] 按阶段 2 页面清单重建路由；移除在线页面、心动模式按钮、在线/收藏歌单分组和网易登录入口；用户入口改为显示登录用户（fixture 提供）。
- [ ] 侧栏菜单按首发页面重组条目，样式以参考实例中的菜单为基线对照。

### 1.2 主题层

- [ ] 对照 [Provider.vue](../../reference/SPlayer/src/components/Global/Provider.vue) 补齐 Naive UI 主题覆盖、字体与全局配置。
- [ ] 实现主题色与封面取色链路（[color.ts](../../reference/SPlayer/src/utils/color.ts)），以固定封面验证生成的 CSS 变量与原项目一致。

### 1.3 Fixture 与 ViewModel

- [ ] 定义歌曲行、专辑/艺术家卡片、列表头、播放器状态的 ViewModel，字段按 Sonora 的媒体语义命名，不含文件路径，不使用网易字段。
- [ ] fixture 可切换空曲库、有数据、加载、服务不可达、播放中/暂停；fixture 复现阶段 2 参考图中的数据，用于同数据对照。

### 1.4 核心模板

每个模板完成后立即对照：

- [ ] 静态首页。
- [ ] 全部歌曲与专辑/歌单详情（列表头、歌曲行、右键菜单、滚动）。
- [ ] 搜索建议面板与结果页。
- [ ] 播放器展示层：底部播放器、进度、音量、队列、全屏播放器（封面、普通歌词、背景）。只接 fixture。

### 1.5 依赖边界与视觉比较

- [ ] 增加检查，禁止前端导入网易 API、Cookie 工具或 `reference/` 下的运行时代码。
- [ ] 引入 Playwright 截图对照流程，复用阶段 2 的环境参数；输出参考图、实际图、差异图与结论；接入 Taskfile（例如 `task test:visual`）。
